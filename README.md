# Daily Assistant - Personal Health & Appointment Reminder

A beautiful, fully-functional personal assistant PWA (Progressive Web App) for managing daily medicines, blood pressure checks, appointments, and morning briefings.

## 📱 Features

✅ **Medicine Reminders** - 2x daily (8:30 AM, 6:30 PM)  
✅ **Blood Pressure Tracking** - 4x daily (9 AM, 12 PM, 3 PM, 6 PM)  
✅ **Appointment Management** - 8-day rolling calendar  
✅ **Daily Briefing** - Automated announcement (8:30 AM)  
✅ **Voice Announcements** - Text-to-speech reminders  
✅ **Voice Input** - Reply to reminders by speaking "yes" or "no"  
✅ **iPhone Home Screen** - Install as native app  
✅ **Offline Support** - Works without internet  

## 🚀 Quick Start

### On iPhone (Recommended)
1. Open Safari
2. Go to: `https://mks-ari.github.io/daily-assistant/`
3. Tap **Share** (⬆️ box icon)
4. Tap **"Add to Home Screen"**
5. Tap **"Add"** ✓

### On Any Browser
Just visit: `https://mks-ari.github.io/daily-assistant/`

## 📋 Modules

### 💊 Medicine
- Morning (8:30 AM) & Evening (6:30 PM)
- Speak reminders aloud
- Voice confirmation available
- 5-minute nag interval if not confirmed

### 💓 Blood Pressure
- 4 daily readings (9 AM, 12 PM, 3 PM, 6 PM)
- Quick confirmation buttons
- Settings to customize times

### 📅 Appointments
- Auto-loads 8 days of events
- Manual event creation
- 30-minute advance reminders
- Date and time display

### 📋 Daily Briefing
- 8:30 AM automatic announcement
- Covers today + tomorrow appointments only
- Non-interruptible playback
- Clear, concise format

## ⚙️ Settings

Each module has customizable settings:
- **Speak reminders aloud** - Enable/disable voice
- **Listen for response** - Voice input option
- **Keep reminding** - Nag interval settings

## 🔔 How Reminders Work

1. **Time arrives** - Reminder fires automatically
2. **Announcement** - Text-to-speech plays
3. **Confirmation** - Tap button or say "yes"/"no"
4. **Nag interval** - Reminds again if not confirmed (5 min)

## 🗓️ Calendar Management

- **Auto-loads** on app startup (8 days ahead)
- **Update manually** - Button to refresh anytime
- **Auto-sync** - Every 4 hours (when app open)
- **Always current** - Rolling window advances daily

## 📱 Install as App

### iPhone
1. Open in Safari

3. Select "Add to Home Screen"

2. Menu → "Install app"
